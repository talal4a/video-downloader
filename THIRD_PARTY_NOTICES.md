# Third-party software

Video Downloader is free and open source (MIT License). It bundles these separate free programs, unchanged:

| Program | What it does | License | Source |
| --- | --- | --- | --- |
| yt-dlp | Reads video pages and downloads media | The Unlicense (public domain) | https://github.com/yt-dlp/yt-dlp |
| FFmpeg / FFprobe | Joins HD video with audio, converts to MP3 | GPL v3 (this build) | https://ffmpeg.org — builds: https://github.com/yt-dlp/FFmpeg-Builds or https://github.com/BtbN/FFmpeg-Builds |
| aria2 | Multi-connection ("turbo") downloads | GPL v2+ | https://github.com/aria2/aria2 |
| Electron | Desktop app shell | MIT | https://github.com/electron/electron |
| Next.js, React | User interface | MIT | https://github.com/vercel/next.js, https://github.com/facebook/react |
| Tailwind CSS, Lucide icons | Styling and icons | MIT / ISC | https://tailwindcss.com, https://lucide.dev |

The GPL programs are included as separate executables. Their source code is available at the links above.
